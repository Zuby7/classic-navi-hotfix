# Classic Navi Hotfix

Signierte Laufzeitdateien für die private Classic-Navi-Installation.

- Manifest: `manifest.json`
- Einmalige Geräteverbindung: `connect.html`
- Änderungen werden erst nach erfolgreicher Signatur- und SHA-256-Prüfung durch die Android-App aktiviert.

Der native Signierschlüssel und das vollständige Android-Projekt sind nicht Bestandteil dieses Repositorys.
